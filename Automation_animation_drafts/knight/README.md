# Automation animation drafts

Every roll the pipeline produces for the Unity characters, kept so the evolution is visible.
One folder per character, one per action, one per roll: the raw clip as Replicate returned it,
its review contact sheet and report, and the finished sheet with its shape file. The prompt
and settings for a roll are in `notes.md` beside it when they differ from the previous roll.

Rolls 1 and 2 of the knight idle were overwritten before this folder existed; from roll 3 on,
everything is kept.
